## 🚀 Projects

### 🌱 GreenLink

A smart agriculture and greenhouse IoT system designed to monitor
environmental conditions and automatically control devices.

**Features include:**

* 🌡️ Temperature monitoring
* 💧 Humidity monitoring
* 🌱 Soil moisture monitoring
* 🚰 Automatic irrigation
* 💨 Fan and mist control
* 📱 IoT monitoring and control
* ⚡ ESP32-based automation

---

### 💊 Smart Pill Dispenser

An IoT-based automated dispenser using an ESP32, RTC, servo motors,
sensors and a mobile dashboard.

The system is designed to automate scheduled dispensing and provide
real-time monitoring.
